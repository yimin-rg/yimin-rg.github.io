UVA 10008 - What's Cryptanalysis? 詳細解析

📌 題目描述

在密碼分析中，字母頻率分析是一個重要工具。給定多行文字，統計每個字母（A-Z）出現的次數，並按照以下規則輸出：

  • 優先按出現次數由大到小排序
  • 如果出現次數相同，則按字母順序排序
  • 只統計英文字母，忽略其他字符
  • 大小寫視為相同字母

🔸 密碼學基礎

字母頻率分析是破解替換密碼的經典方法。在英文中，字母 E 出現頻率最高（約12.7%），其次是 T、A、O 等。

排序規則：頻率高者優先，頻率相同則字母順序優先

💡 解題思路

核心概念是 計數與排序：

  • 使用 map 統計每個字母的出現次數
  • 讀取多行輸入，逐字符處理
  • 自定義比較函數實現雙重排序規則
  • 將統計結果轉為 vector 進行排序

📝 程式碼解析

// CPE 必考題目 - 字母頻率統計
#include<bits/stdc++.h>   // 引入所有標準 C++ 函式庫
using namespace std;       // 使用標準命名空間

// 自定義比較函數：用於排序 pair<char, int>
bool cmp(pair<char,int> a, pair<char,int> b) {
    // 如果出現次數相同，按字母順序排序（A < B < C...）
    if(a.second == b.second) {
        return a.first < b.first;  // 字母小的排前面
    }
    // 否則按出現次數由大到小排序
    return a.second > b.second;     // 次數多的排前面
}

int main() {
    ios::sync_with_stdio(false); // 加速 cin/cout
    cin.tie(nullptr);            // 取消綁定
    cout.tie(nullptr);
    
    int t;                          // 輸入行數
    cin >> t;
    cin.ignore();                    // 忽略換行符，準備讀取整行
    
    map<char, int> mp;               // 用 map 統計字母出現次數
    
    // 處理 t 行輸入
    for(int i = 0; i < t; i++) {
        string line;                 // 讀取一整行
        getline(cin, line);
        
        stringstream ss(line);       // 用 stringstream 逐字符處理
        char c;
        
        // 逐字符讀取並統計
        while(ss >> c) {
            // 如果是字母，轉為大寫並統計
            if(isalpha(c)) {
                mp[toupper(c)] += 1; // 轉大寫後計數 +1
            }
        }
    }
    
    // 將 map 轉為 vector 以便排序
    vector<pair<char, int>> v;
    for(auto p : mp) {
        v.push_back({p.first, p.second}); // 加入 (字母, 次數) pair
    }
    
    // 使用自定義比較函數排序
    sort(v.begin(), v.end(), cmp);
    
    // 輸出結果：字母 + 空格 + 出現次數
    for(auto p : v) {
        cout << p.first << " " << p.second << endl;
    }
}

🔧 關鍵技巧

  • Map 統計：使用 map<char, int> 自動統計字母頻率
  • 字符處理：使用 isalpha() 判斷字母，toupper() 轉大寫
  • 自定義排序：實現雙重排序規則的比較函數
  • StringStream：使用 stringstream 逐字符解析
  • Getline：處理包含空格的整行輸入

📊 測試範例

// 輸入：
3
This is a test.
Count me 1 2 3 ABC!
Wow!!

// 處理過程：
// 行1: "This is a test." → T:2, H:1, I:2, S:3, A:1, E:1
// 行2: "Count me 1 2 3 ABC!" → C:2, O:1, U:1, N:1, T:1, M:1, E:1, A:1, B:1
// 行3: "Wow!!" → W:2, O:1

// 統計結果：S:3, T:3, I:2, W:2, C:2, A:2, E:2, ...

S 3
T 3
C 2
I 2
W 2
A 1
B 1
E 1
H 1
M 1
N 1
O 1

🧮 算法分析

時間複雜度：

  • 統計階段：O(N)，N 為總字符數
  • 排序階段：O(K log K)，K 為不同字母數量（最多26）
  • 總複雜度：O(N + K log K)

空間複雜度：O(K)，用於儲存字母計數

⚠️ 注意事項

  • 使用 cin.ignore() 忽略第一行後的換行符
  • 只統計字母，忽略數字、標點符號和空格
  • 大小寫統一轉為大寫處理
  • 自定義比較函數的邏輯要正確（頻率優先，字母次優先）
  • 注意 stringstream 會自動跳過空格

🎯 學習重點

這題是經典的 統計與排序 問題。 重點學習自定義比較函數、字符處理函數的使用， 以及處理多行字符串輸入的技巧。 對於理解 STL 容器和算法很有幫助， 也是密碼學入門的好例子。

🔗 相關概念

  • Map 容器：自動排序的鍵值對容器
  • 字符函數：isalpha(), toupper(), tolower()
  • 自定義排序：比較函數的設計原則
  • 字符串處理：getline 與 stringstream 的配合使用
