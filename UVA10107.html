UVA 10107 - What is the Median? 詳細解析

📌 題目描述

這是一道經典的 動態中位數 問題。程序會持續讀入整數，每讀入一個數字後，就要輸出當前所有數字的中位數。中位數的定義如下：

  • 如果數字個數為奇數，中位數是排序後中間的數字
  • 如果數字個數為偶數，中位數是排序後中間兩個數字的平均值

🔸 中位數概念

中位數（Median）是統計學中的重要概念，表示一組數據排序後的中間值：

奇數個數：median = arr[n/2]
偶數個數：median = (arr[n/2-1] + arr[n/2]) / 2

💡 解題思路

核心概念是 動態維護有序序列：

  • 每次讀入新數字後加入 vector
  • 立即對整個 vector 進行排序
  • 根據當前數字個數計算中位數
  • 使用 EOF 方式持續讀取直到輸入結束

📝 程式碼解析

// UVA 歷屆經典題 - 動態中位數
#include<bits/stdc++.h>   // 引入所有標準 C++ 函式庫
using namespace std;       // 使用標準命名空間

int main() {
    ios::sync_with_stdio(false); // 加速 cin/cout
    cin.tie(nullptr);            // 取消綁定
    cout.tie(nullptr);
    
    long long int n;             // 輸入的數字（使用 long long 避免溢出）
    vector<long long int> v;      // 儲存所有數字的動態陣列
    int i = 0;                    // 計數器，表示當前數字個數
    
    // 持續讀取直到 EOF（End of File）
    while(cin >> n) {
        v.push_back(n);           // 將新數字加入 vector
        sort(v.begin(), v.end()); // 每次都重新排序（保持有序）
        
        // 判斷當前數字個數的奇偶性
        if(i % 2 == 1) {
            // 偶數個數字（i+1 個，因為 i 從 0 開始）
            // 中位數 = 中間兩個數的平均值
            cout << (v[i/2] + v[i/2 + 1]) / 2 << endl;
        } else {
            // 奇數個數字
            // 中位數 = 中間的數字
            cout << v[i/2] << endl;
        }
        
        i += 1;                   // 計數器加 1
    }
}

🔧 關鍵技巧

  • 動態排序：每次新增數字後立即排序維持有序狀態
  • 索引計算：正確計算奇偶數情況下的中位數索引
  • EOF 處理：使用 while(cin >> n) 持續讀取
  • 數據類型：使用 long long 避免數字溢出
  • 整數除法：利用整數除法特性計算平均值

📊 測試範例

// 輸入：1 2 3 4 5

// 處理過程：
// 步驟1：讀入 1
//   v = [1], i = 0（奇數個）
//   中位數 = v[0] = 1

// 步驟2：讀入 2
//   v = [1, 2], i = 1（偶數個）
//   中位數 = (v[0] + v[1]) / 2 = (1 + 2) / 2 = 1

// 步驟3：讀入 3
//   v = [1, 2, 3], i = 2（奇數個）
//   中位數 = v[1] = 2

// 步驟4：讀入 4
//   v = [1, 2, 3, 4], i = 3（偶數個）
//   中位數 = (v[1] + v[2]) / 2 = (2 + 3) / 2 = 2

// 步驟5：讀入 5
//   v = [1, 2, 3, 4, 5], i = 4（奇數個）
//   中位數 = v[2] = 3

// 輸出：
1
1
2
2
3

🧮 算法分析

時間複雜度：

  • 每次插入：O(n log n)（排序）
  • 總計 n 次插入：O(n² log n)

空間複雜度：O(n)，用於儲存所有數字

優化方案：可使用兩個 priority_queue 實現 O(log n) 插入

⚠️ 性能警告

此解法雖然直觀易懂，但在大數據量下效率較低。每次都重新排序整個陣列會導致 O(n² log n) 的時間複雜度。在競賽中，更高效的做法是使用雙堆（兩個 priority_queue）來維護中位數。

  • 索引處理：正確處理奇偶數情況的索引計算
  • EOF 輸入：處理不定長度的輸入流
  • 整數運算：整數除法在平均值計算中的應用

💡 優化思路

進階解法：雙堆法

  • 使用 max_heap 維護較小的一半數字
  • 使用 min_heap 維護較大的一半數字
  • 保持兩個堆的大小平衡
  • 中位數就是堆頂元素或兩個堆頂的平均值
  • 時間複雜度優化為 O(n log n)

⚠️ 注意事項

  • 使用 long long 防止數字溢出
  • 正確理解計數器 i 和實際數字個數的關係
  • 整數除法會自動截去小數部分
  • 索引計算要考慮從 0 開始的特性
  • EOF 輸入處理需要熟練掌握
