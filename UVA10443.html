UVA 10443 - Rock, Scissors, Paper 詳細解析

📌 題目描述

給定一個 R×C 的二維矩陣，矩陣中每個位置都是 'R'（石頭）、'S'（剪刀）或 'P'（布）。根據剪刀石頭布的遊戲規則，每天每個位置都會嘗試「佔領」相鄰的位置（上下左右四個方向）。需要模擬 N 天後矩陣的狀態。

遊戲規則

R（石頭）勝 S（剪刀）
S（剪刀）勝 P（布）
P（布）勝 R（石頭）

💡 解題思路

這是一個 2D 模擬 問題，核心概念：

  • 每天同時進行所有的「佔領」動作
  • 只有勝利方能佔領失敗方的位置
  • 需要使用 雙緩衝 技術避免更新衝突
  • 模擬 N 天的變化過程

📝 程式碼解析

#include<bits/stdc++.h>   // 引入所有標準 C++ 函式庫
using namespace std;       // 使用標準命名空間

int main(){
    ios::sync_with_stdio(false); // 加速 cin/cout
    cin.tie(nullptr);            // 取消 cin 與 cout 綁定
    cout.tie(nullptr);           // 取消 cout 綁定
    
    int t; cin >> t;             // 讀取測資組數
    
    for(int i = 0; i < t; i++){
        if(i != 0) cout << endl; // 測資間空行分隔（第一組前不用空行）
        
        int r, c, n;             // r=列數, c=欄數, n=天數
        cin >> r >> c >> n;
        
        // 建立 r×c 的二維矩陣，初始化為 '0'
        vector<vector<char>> v(r, vector<char>(c, '0'));
        
        // 讀取初始矩陣狀態
        for(int j = 0; j < r; j++){
            string x; cin >> x;  // 讀取一整列
            for(int k = 0; k < x.length(); k++){
                v[j][k] = x[k];  // 逐字元存入矩陣
            }
        }
        
        vector<vector<char>> tmp = v; // 建立副本作為緩衝區
        
        // 定義四個方向的移動向量：下、上、右、左
        vector<int> dx = {1, -1, 0, 0};
        vector<int> dy = {0, 0, 1, -1};
        
        // 模擬 n 天
        for(int m = 0; m < n; m++){
            // 遍歷矩陣中每個位置
            for(int j = 0; j < r; j++){
                for(int k = 0; k < c; k++){
                    // 檢查四個相鄰方向
                    for(int l = 0; l < 4; l++){
                        // 計算相鄰位置座標
                        int newX = j + dx[l];
                        int newY = k + dy[l];
                        
                        // 檢查邊界條件
                        if(newX < r && newX >= 0 && newY < c && newY >= 0){
                            // 檢查是否能佔領相鄰位置
                            // R勝S, S勝P, P勝R
                            if((v[j][k] == 'R' && v[newX][newY] == 'S') ||
                               (v[j][k] == 'S' && v[newX][newY] == 'P') ||
                               (v[j][k] == 'P' && v[newX][newY] == 'R')){
                                // 佔領相鄰位置
                                tmp[newX][newY] = v[j][k];
                            }
                        }
                    }
                }
            }
            v = tmp; // 更新矩陣狀態（雙緩衝技術）
        }
        
        // 輸出最終矩陣狀態
        for(int j = 0; j < r; j++){
            for(int k = 0; k < c; k++){
                cout << v[j][k];
            }
            cout << endl;
        }
    }
}

🔧 關鍵技巧

  • 雙緩衝技術：使用 tmp 副本避免同步更新問題
  • 方向向量：dx 和 dy 簡化四方向遍歷
  • 邊界檢查：確保不超出矩陣範圍
  • 遊戲邏輯：明確的勝負關係判斷

📊 測試範例

// 輸入：
1
3 3 1
RSP
SRP
PRS

// 第0天（初始狀態）：
RSP
SRP  
PRS

// 第1天後：
RRR  （R佔領了相鄰的S）
RRP  （P佔領了相鄰的R，但同時R也在擴張）
RRS  （類似的佔領過程）

// 解釋：
// - 位置(0,0)的R佔領了位置(0,1)的S
// - 位置(0,2)的P佔領了位置(1,2)的R  
// - 各種佔領同時發生

⚠️ 注意事項

  • 所有佔領動作在同一天內 同時發生
  • 必須使用雙緩衝，避免更新過程中的數據衝突
  • 測資組之間要有空行分隔（除了第一組）
  • 邊界檢查很重要，避免陣列越界

🎯 學習重點

這題考驗 2D 陣列模擬 和 狀態同步更新。 雙緩衝技術是解決同步更新問題的經典方法，在遊戲開發和模擬程序中非常常見。 理解這個概念對解決類似的格子世界模擬題目很有幫助。
