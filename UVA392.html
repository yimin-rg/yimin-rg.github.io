UVA 392 - Polynomial Showdown 詳細解析

📌 題目描述

給定一個多項式的係數陣列，需要將其轉換為標準的數學表示法字串。陣列中第一個元素是最高次項的係數，最後一個元素是常數項。

💡 解題思路

這題主要考驗 字串格式化 的處理能力，需要注意：

  • 正負號的處理
  • 係數為 ±1 的特殊處理
  • 零係數項目要完全省略
  • 若所有係數都為 0，輸出 0

📝 程式碼解析

#include <bits/stdc++.h>   // 引入標頭檔，包含所有標準 C++ 函式庫
        using namespace std;       // 使用標準命名空間
        
        int main() {
            ios::sync_with_stdio(false); // 提升 cin/cout 效率
            cin.tie(nullptr);            // 取消 cin 與 cout 綁定，避免 flush
        
            string line;
            // 逐行讀取輸入（每一行是一組多項式係數）
            while (getline(cin, line)) {
                vector<int> conf;        // 儲存多項式係數
                stringstream ss(line);   // 用 stringstream 拆解一行輸入
                int x;
                while (ss >> x) conf.push_back(x); // 依序讀入係數
        
                reverse(conf.begin(), conf.end()); // 反轉，使 index 對應次方數
        
                int sum = 0;
                for (int c : conf) sum += c;       // 檢查是否所有係數都為 0
        
                if (sum == 0) {
                    cout << 0 << "\n";             // 如果全為 0，輸出 0
                    continue;                      // 跳過這筆測資
                }
        
                int skip = 0; // 記錄被跳過的零係數項數
                for (int i = conf.size() - 1; i >= 0; i--) {
                    if (conf[i] == 0) {            // 跳過零係數
                        skip++;
                        continue;
                    }
        
                    // 處理正負號
                    if (i != conf.size() - 1 - skip && conf[i] > 0) cout << " + ";
                    else if (i == conf.size() - 1 - skip && conf[i] < 0) cout << "-";
                    else if (i != conf.size() - 1 - skip && conf[i] < 0) cout << " - ";
        
                    // 處理係數顯示
                    if ((abs(conf[i]) == 1 && i != 0)) cout << "x";         // 係數 ±1（非常數）只輸出 x
                    else if (i != 0) cout << abs(conf[i]) << "x";           // 一般係數（非常數）輸出 數字x
                    else cout << abs(conf[i]);                              // 常數項輸出數字
        
                    // 處理次方顯示
                    if (i > 1) cout << "^" << i;                           // 次方大於 1 時輸出 ^次方
                }
                cout << "\n"; // 換行輸出
            }
        }

🔧 關鍵技巧

  • 向量反轉：讓索引值對應次方
  • 零係數處理：跳過並修正正負號
  • 邊界條件：第一項、最後一項要特別處理
  • 字串流：使用 stringstream 解析輸入

📊 測試範例

// 輸入：1 -1 1 -1 1 -1
// 輸出：x^5 - x^4 + x^3 - x^2 + x - 1

// 輸入：0 0 0 0 0 0
// 輸出：0

// 輸入：1 0 -2 0 3
// 輸出：x^4 - 2x^2 + 3
